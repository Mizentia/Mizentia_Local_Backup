নতুন গিটহাব অ্যাকাউন্ট যুক্ত করুন

আপনার GitHub Personal Access Token (PAT) এবং একটি লেবেল প্রদান করে অ্যাকাউন্ট ভেরিফাই করুন।

💡 টোকেন (PAT) যেভাবে তৈরি করবেন:
  1. GitHub-এ লগইন করে ডানদিকের প্রোফাইল ছবিতে ক্লিক করে Settings-এ যান।
  2. বামে স্ক্রোল করে একেবারে নিচে Developer settings-এ যান।
  3. Personal access tokens > Tokens (classic) নির্বাচন করুন।
  4. Generate new token (classic) বাটনে ক্লিক করুন।
  5. একটি নোট লিখুন (যেমন: Mizentia Backup) এবং repo ও workflow স্কোপ দুটি টিক দিন।
  6. একেবারে নিচে Generate token বাটনে ক্লিক করে টোকেনটি কপি করে নিচে পেস্ট করুন।
টোকেনে অবশ্যই repo স্কোপের রিড/রাইট পারমিশন থাকতে হবে।
